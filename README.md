# A.S.C. Updater

A.S.C. Updater est le programme utilisé pour maintenir **A.S.C. Launcher** à jour.

## Fonctionnement

L'Updater ne gère pas les fichiers du modpack. Ils sont gérées automatiquement par **A.S.C. Launcher**.

## Installation

Téléchargez `ASC-Updater.exe` depuis la dernière release.

Placez-le à l'emplacement de votre choix et utilisez-le pour lancer A.S.C. Launcher.

L'Updater téléchargera automatiquement A.S.C. Launcher lors du premier lancement si celui-ci n'est pas encore installé.
